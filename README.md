# Carrera de Caballos — Desafíos Locos

Juego independiente para dos competidores: caballo rosa y caballo azul.

## Cómo jugar
1. Abre `index.html` en Microsoft Edge o Google Chrome.
2. Presiona **INICIAR CARRERA**.
3. Caballo rosa: tecla **A**. Caballo azul: tecla **L**. También puedes usar los botones en pantalla.
4. Cada 5 pulsaciones el caballo avanza y su contador vuelve a cero. Gana quien llegue primero a la meta.

## Personalización
En el panel de edición puedes cambiar la dificultad, pulsaciones por avance, teclas, nombres, imágenes de los caballos, fondo, música y efectos de sonido. También puedes activar o desactivar las instrucciones habladas.

Los archivos que selecciones desde tu computadora se usan localmente en el navegador; no se suben automáticamente a GitHub.

## Compatibilidad
Diseñado para navegadores modernos en Windows 10 y Windows 11. Es un juego web local y no requiere instalación. Los pulsadores USB deben estar configurados para enviar las teclas asignadas (A y L).
