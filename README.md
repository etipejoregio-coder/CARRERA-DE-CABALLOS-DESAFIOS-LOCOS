# Carrera de Caballos — Desafíos Locos

Juego de escritorio para Windows 10 y Windows 11, con dos carriles independientes:
- Carril superior: caballo azul (tecla **L**).
- Carril inferior: caballo rosa (tecla **A**).

Los caballos corren hacia la meta. Cada jugador avanza al completar el número configurado de pulsaciones. También se puede jugar con los botones que aparecen en pantalla.

## Descargar e instalar en Windows

1. Entra a la pestaña **Actions** de este repositorio.
2. Abre la ejecución más reciente llamada **Crear instalador de Windows**.
3. Cuando termine correctamente, baja hasta **Artifacts**.
4. Descarga **Instalador-Carrera-de-Caballos-Windows** y extrae el ZIP.
5. Ejecuta el archivo **Carrera de Caballos - Desafíos Locos Setup.exe**.
6. Sigue el asistente. Puedes crear un acceso directo en el escritorio y abrir el juego desde Windows.

Si Windows muestra una advertencia de SmartScreen porque el instalador no tiene firma digital, verifica que lo descargaste de este repositorio y selecciona la opción para continuar si confías en el archivo.

## Personalización

Dentro del juego puedes cambiar la dificultad, las pulsaciones necesarias para avanzar, las teclas, los nombres, las imágenes de los caballos, el fondo, la música y los efectos de sonido.

Los archivos que selecciones desde tu PC se usan localmente en el juego.

## Controles

- **A:** caballo rosa.
- **L:** caballo azul.
- **Enter:** iniciar la carrera.
- También puedes usar los botones en pantalla.

## Proyecto

La aplicación de Windows se construye con Electron. El código del juego permanece en este repositorio independiente.
